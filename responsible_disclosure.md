# Responsible disclosure

To report a security vulnerability in Zapp for iOS, please use GitHub Security
Advisories on this repository rather than opening a public issue:

https://github.com/JustZappIt/ios-zapp/security/advisories/new

See [SECURITY.md](SECURITY.md) for scope and the full policy.

For vulnerabilities in the upstream Zcash Swift SDK, follow its own process:
https://github.com/zcash/ZcashLightClientKit/blob/master/responsible_disclosure.md
